# experiment-tracker-lite\n\nFile-based experiment tracker with a subset of the MLflow fluent API, run search with MLflow filter syntax, and a reproducible static comparison site.\n\n## The Problem\nSmall ML projects need to record runs, parameters, and metrics to compare results, but running a dedicated tracking server and database introduces unnecessary overhead, while tracking runs in spreadsheets causes drift from the codebase. This library stores runs as plain, atomic JSON and JSONL files that are reviewable in Git, provides MLflow-compatible API calls for easy migration, and builds a static HTML comparison site that is byte-identical when rebuilt from the same store.\n\n## Installation\n```bash\npip install experiment-tracker-lite\n```\n\n## Usage\n```python\nimport experiment_tracker_lite as mlflow\n\nmlflow.set_tracking_root("./mlruns")\nmlflow.set_experiment("mnist")\nwith mlflow.start_run(run_name="baseline") as run:\n    mlflow.log_param("lr", "0.01")\n    mlflow.log_metric("acc", 0.92, step=1)\nruns = mlflow.search_runs(filter_string="metrics.acc > 0.9 and params.lr = '0.01'")\nmlflow.build_site("./site")\n```\n\n## Public API Summary\n- **Core Functions**: `set_tracking_root`, `set_experiment`, `start_run`, `end_run`, `log_param`, `log_params`, `log_metric`, `log_metrics`, `set_tag`, `log_artifact`, `get_run`, `search_runs`, `build_site`.\n- **Errors**: `TrackerError` is raised with the following codes: `invalid_parameter_value`, `resource_does_not_exist`, `invalid_state`, `bad_filter`, `limit_exceeded`.\n- **Limits**: Keys (1-250 chars), Params/Tags (<6,000 chars), Filter strings (<1,000 chars), Metrics (<100,000 points), Artifacts (<100 MiB).\n\n## Why not MLflow?\nThis utility requires no server or database, stores data in human-readable plain files reviewable in Git, and provides MLflow-compatible API calls for easy future migration if the project scales.\n\n## Security\nSee [docs/SECURITY.md](docs/SECURITY.md).
