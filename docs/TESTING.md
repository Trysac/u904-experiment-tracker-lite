# Testing\n\n## Running\n`pytest --cov=experiment_tracker_lite`\n\n## Policy\n- Branch coverage must stay at or above 80%.\n- Tests exercise the public API and assert observable effects (return values, exceptions).\n- Tests are deterministic; no network, no wall clock, no order dependence.\n\n## Test Modules\n- `tests/test_tracker.py`: Exercises fluent API and tracker state.\n- `tests/test_storage.py`: Verifies atomic write mechanics and layout.\n- `tests/test_search.py`: Validates lexer, parser, and filter evaluation logic.\n- `tests/test_models.py`: Checks data entities.\n- `tests/test_cli.py`: Confirms CLI commands.\n- `tests/test_site.py`: Checks static site generator deterministic output.\n\n## Conformance Tier\nTests marked `@pytest.mark.conformance` are optional and test compatibility against `mlflow`.
